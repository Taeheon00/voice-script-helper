메뉴 각 기능 설명

0. 허깅페이스 토큰설정, 토큰은 사이트 가입후 토큰생성후 3개의 약관 동의 해주고 hf로 시작되는 토큰을 등록하세요
1. 실시간으로 브라우저의 소리만 녹음 됩니다.
- 모든 브라우저의 소리가 들어가니 하나의 브라우저의 단일 탭에서 재생되는 음원만 녹화하는 것을 권장합니다.
- 브라우저외의 게임,마이크,디스코드등의 외부 소리는 녹화되지 않습니다.
2. 이미 녹음된 wav음원으로 분석을 실시합니다. 
- 1,2번 모두 단계는 동일하며, 등록된 알고리즘이 없는 경우 기본 분석만 가능합니다.
- 기본 분석은 단일 화자로만 진행 해주시기 바랍니다.
- 단일/다중 화자 알고리즘 분석은 해당음원이 등록된 알고리즘 화자와 음역대가 일치하는경우에만 사용 가능합니다.
3. 기본 분석에서 추출된 세그먼트를 web ui에 불러와 txt 대사 내용을 수정합니다.
- 저장하기를 눌러야만 수정및 삭제 내용이 적용 됩니다. 
- 화자이름을 지정하고 알고리즘을 등록및 업데이트를 할 수 있습니다.
- 등록 및 업데이트가 끝난 알고리즘은 1,2번 메뉴의 단일/다중분석에 사용 가능해집니다.

* 해당 프로그램은 오디오에서 화자의 이름을 매칭 시키고 해당 화자의 자주 오인식되는 단어를 보정하여 txt 대본을 작성하는 편의성을 올려주는 ai입니다. TTS학습 데이터셋으로 사용가능하지만 TTS학습은 현재 지원하지 않습니다.
