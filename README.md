## 🛠️ 설치 가이드 (Installation)

깃허브(GitHub)에서 소스코드를 다운로드하고 필요한 파이썬 라이브러리를 설치하는 방법입니다.

1. **저장소 클론 (Clone Repository)**
   - 터미널(CMD 또는 PowerShell)을 열고 아래 명령어를 입력하여 프로젝트를 다운로드합니다.
   - git clone <깃허브_REPOSITORY_URL>
   - cd voice-script-helper
   - python 3.10 환경에서 진행해주시기바랍니다. (3.10이상 버전에서 필수 설치 패키지 호환이 안될 수 있습니다.)

2. **가상 환경 생성 및 활성화 (권장)**
   - python -m venv venv
   - 윈도우(Windows)의 경우: venv\Scripts\activate

3. **필수 라이브러리 설치**
   - 프로젝트 구동에 필요한 라이브러리를 일괄 설치합니다.
   - pip install -r requirements.txt
   - *(참고: 원활한 오디오 처리 및 AI 모델 구동을 위해 PyTorch, Transformers, Gradio 등의 패키지가 포함되어 있습니다.)*

## 메뉴 각 기능 설명

0. **허깅페이스 토큰 설정**
   - 허깅페이스 사이트 가입 후 토큰을 생성하고, 3개의 약관 동의 후 "hf_"로 시작하는 토큰을 등록하세요.

1. **실시간 녹화**
   - 실시간으로 브라우저의 소리만 녹음됩니다.
   - 모든 브라우저의 소리가 들어가니 하나의 브라우저의 단일 탭에서 재생되는 음원만 녹화하는 것을 권장합니다.
   - 브라우저 외의 게임, 마이크, 디스코드 등의 외부 소리는 녹화되지 않습니다.
   - 자동 녹화 기능은 정해진 시간만큼 자동녹화되며, 중간에 강제 녹화 종료가 가능합니다.

2. **파일 분석**
   - 이미 녹음된 wav 음원으로 분석을 실시합니다.
   - 1, 2번 모두 단계는 동일하며, 등록된 알고리즘이 없는 경우 기본 분석만 가능합니다.
   - 기본 분석은 단일 화자로만 진행하는것을 권장합니다.
   - 단일/다중 화자 알고리즘 분석은 해당 음원이 등록된 알고리즘 화자와 음역대가 일치하는 경우에만 사용 가능합니다.

3. **Web UI 수정 및 알고리즘 관리**
   - 기본 분석에서 추출된 세그먼트를 Web UI에 불러와 txt 대사 내용을 수정합니다.
   - 저장하기를 눌러야만 수정 및 삭제 내용이 적용됩니다.
   - 화자 이름을 지정하고 알고리즘을 등록 및 업데이트를 할 수 있습니다.
   - 등록 및 업데이트가 끝난 알고리즘은 1, 2번 메뉴의 단일/다중 분석에 사용 가능해집니다.

4. **소형LLM 대화형 Chat bot**
   - Web UI에서 등록/업데이트한 알고리즘을 선택하여 해당 알고리즘의 세그먼트 txt내용을 학습한 쳇봇입니다.

* 해당 프로그램은 오디오에서 화자의 이름을 매칭시키고 해당 화자의 자주 오인식되는 단어를 보정하여 txt 대본을 작성하는 편의성을 올려주는 AI입니다. TTS 학습 데이터셋으로 사용 가능하지만 TTS 학습은 현재 지원하지 않습니다.
